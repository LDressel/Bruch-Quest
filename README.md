# Bruch-Quest

Lernspiel zu Bruchteilen für die 6. Klasse (Mittelschule Bayern).

- 5 Themenwelten mit je 3 Levels und einem Miniboss
- Bosskampf gegen den Chaos-Oni und ein geheimer Endgegner
- Spieler-Level mit Erfahrungspunkten, Ausrüstung als Beute von Bossen
- Themen: Brüche darstellen · Gemischte Zahlen · Bruchteil und Ganzes · Bruchteile von Größen · Zahlenstrahl
- Läuft komplett im Browser, ohne Anmeldung und ohne externe Server. Der Fortschritt wird nur lokal im Browser gespeichert.

Spielen: `index.html` öffnen oder über GitHub Pages aufrufen.
